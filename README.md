## Descripción
Los presentes archivos son el código fuente de nuestro sistema CRM, Bubbles Web App, la cual tiene el objetivo de conectar a la empresa con el cliente de una forma más atractiva e interactiva, haciendo el uso de puntos que el usuario cliente pueda canjear por descuentos en servicios.
## Inicialización
Para inicializar el proyecto, es necesario tener XAMPP instalado, y configurar los queries create en la base de datos MySQL de XAMPP e inicializarla. Por último, inicializar el servidor Apache.
